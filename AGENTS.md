# Правила работы над проектами Ivan Studio

1. Перед изменениями сначала изучай существующую структуру проекта и текущий код.
2. Не переписывай рабочий проект целиком без необходимости. Предпочитай точечные изменения.
3. Интерфейс и пользовательский текст по умолчанию должны быть на русском языке.
4. Всегда обеспечивай корректную адаптацию под desktop, tablet и mobile.
5. Следи за доступностью, семантической HTML-разметкой и базовым SEO.
6. Не добавляй библиотеки, зависимости и фреймворки без реальной необходимости.
7. Не используй шаблонный AI-дизайн: избегай бессмысленных градиентов, чрезмерных glow-эффектов, случайных карточек и декоративных элементов без функции.
8. Дизайн должен быть современным, чистым и ориентированным на коммерческий результат.
9. Перед завершением задачи проверяй код на очевидные ошибки и, когда возможно, запускай подходящие проверки проекта.
10. Не выполняй git commit, git push, публикацию или другие необратимые действия без отдельного прямого запроса пользователя.
11. Не удаляй существующий функционал без необходимости.
12. После выполнения задачи кратко сообщай:
    - что изменено;
    - какие файлы затронуты;
    - какие проверки выполнены;
    - есть ли что-то, что пользователь должен проверить вручную.
